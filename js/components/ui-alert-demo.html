🔔 UI Alert Component Demo

A versatile web component for loaders, toasts, and notifications

📍 Full Page Loader

showFullPageLoader(true, 'Loading data...');
showFullPageLoader(false);

🍞 Toast Messages

showToastMessage({ type: 'success', message: 'Saved!', title: 'Success' });

⚠️ Validation Notification

showValidationNotification('Please fill in all required fields');

📝 Inline Messages

MessageHelper.success('Saved!', '#message-container');
MessageHelper.error('Failed!', '#container', { title: 'Error' });
