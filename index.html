About FormGroup Component

The FormGroup component is a custom HTML element that enhances form validation with:

  • ✅ Custom validation messages
  • ✅ Real-time validation feedback
  • ✅ Button state management (disabled until valid)
  • ✅ Custom styling support
  • ✅ Programmatic API
  • ✅ Custom events for validation states

Available Examples

Basic Validation

Required fields, email validation, pattern matching, and select dropdowns.

Length Validation

Minlength and maxlength validation for text inputs and textareas.

Number Validation

Min/max ranges, step increments, and numeric constraints.

Date Validation

Date and time validation with min/max constraints.

Advanced password validation with requirements checking and confirm password matching.

Custom Styling

Custom CSS styling with CSS variables for theming.

API Demo

Programmatic API and custom event demonstrations.

Features

🔒 Button Validation

Submit buttons are automatically disabled until all form fields are valid.

⚡ Real-time Feedback

Validation occurs as users type, providing immediate feedback.

🎨 Customizable

Easy to style with CSS variables and custom validation messages.
